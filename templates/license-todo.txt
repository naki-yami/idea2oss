第 0 步要回答一个问题：你是想让人尽量用，还是想让衍生作品也开源？

  想被最广泛使用（含闭源产品）        → MIT（最短最宽松，企业最熟；无专利授权条款）
  同样宽松但要显式专利授权            → Apache-2.0（大公司合规偏好；需标注改过哪些文件）
  想让衍生作品也开源                  → GPL-3.0（传染性；企业政策常直接禁止）
  想让网络服务的改动也开源            → AGPL-3.0（覆盖 SaaS；最容易被企业政策挡掉）

落地三步（三处必须一致，缺一处 GitHub 会显示 Unknown）：
  1. 仓库根目录放 LICENSE 全文（替换本文件）
  2. 包元数据写 license 字段（package.json / pyproject.toml / Cargo.toml），用标准 SPDX 标识
  3. README 末尾写明许可

选定后请删除本提示，把许可证全文粘进来。
