# triage 标签

<!-- 第 2 章（二）· setup 一次性配置的产物之二 ｜ 每个标签名等于它的角色名 -->

| 标签 | 含义 |
|---|---|
| needs-triage | 待维护者评估 |
| needs-info | 等报告者补信息 |
| ready-for-agent | 规格完整，可交给无人值守的智能体 |
| ready-for-human | 需要人工实现 |
| wontfix | 不处理 |

## 已知坑

`to-spec` 产出的文档会被打上 `ready-for-agent`，无人值守代理可能整份实现而不是捡票据切片。
**拆票跑完后把标签摘掉**，或在代理提示词里明确排除父级文档。
