# ADR-0002　技能正文用中文，`description` 带英文关键词

- **状态**：已接受（2026-09-30）

## 背景

技能的 `description` 决定它能不能被自动触发，正文决定被触发后代理读到什么。这套技能集的源材料（《从想法到开源 · AI 结对开发流程手册 V3》）是中文的，作者和使用者的工作语言也是中文；但技能可能被拿到英文提示词环境里用。这是一个「脱离上下文会费解」的决定——看到「中文正文 + 英文 keywords」的人会问为什么不统一语言。

## 决策

**正文全中文；frontmatter 的 `description` 用中文写两到三句，末尾追加一行 `keywords: <英文关键词>`；`whenToUse` 用中文。**

## 后果

**得到的**：

- 与源手册同一套术语（票据、接缝、台账、判据、兜底路径），翻译损耗为零。
- 英文环境仍能命中：`keywords` 覆盖 `decision ledger` / `open source launch` / `dual axis review` 这类检索词。

**付出的**：

- 英文使用者读正文有门槛，需要自己过一遍翻译。
- 中英混排要靠人工守规范（半角空格、全角标点），`validate_skills.py` 只能检查部分格式。

**判断错了怎么回退**：为每个技能增加 `references/en.md` 英文摘要（不翻全文，只翻判据与动作两节），`description` 保持现状；技能名不变，调用面不受影响。**触发条件**：出现第一个非中文母语的 issue 提出者。
